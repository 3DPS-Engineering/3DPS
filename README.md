## Política de evidencias

Las tareas académicas aprobadas acreditan trabajo de diseño revisado, **no** productos fabricados, medidos físicamente, certificados ni listos para comercialización. Se distinguen expresamente diseño, fabricación, ensayos y conformidad normativa. No se publican archivos de fabricación ni datos de terceros sin comprobación y autorización.
